Café & Código

Projeto de desenvolvimento de uma página web para uma cafeteria fictícia, utilizando HTML e CSS.

Sobre o projeto

O Café & Código é um projeto criado com o objetivo de praticar os fundamentos do desenvolvimento web, explorando a estrutura HTML e a estilização com CSS.

A proposta é apresentar uma cafeteria de forma agradável, destacando imagens, informações e elementos visuais relacionados à experiência de tomar um bom café.

Tecnologias utilizadas

- HTML5
- CSS3

Estrutura do projeto

- `index.html`: estrutura e conteúdo da página.
- `style.css`: estilos visuais da página.
- `img/`: imagens utilizadas no projeto.

Objetivo

Praticar os conhecimentos iniciais de desenvolvimento web e aprender a organizar e versionar projetos utilizando o GitHub.
